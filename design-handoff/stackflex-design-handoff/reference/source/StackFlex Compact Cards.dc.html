Recommendation: C, hybrid. The page, the Results preview and the landing mock use the horizontal card. The square card stays on the images people post (social post, banners), where it's the visual. Both use the same tool data, colors and Main treatment.

Components

StackCardRow (new): the horizontal card. Props: tool, main?, size "md" (216×72, logo circle 42, name 15) or "sm" (fluid, logo circle 36, name 14, min-height 64). It uses the same Tool data as StackCard.

ToolTag (new): 28px pill with a 20px logo circle, a 1.5px ring in the tool color, and the name at 12.5/600. No model, no foil.

StackCard (square) is unchanged and stays in SocialCardArt and BannerArt.

Page layout

Order: identity → My AI Stack (AI Apps, AI-Powered Software) → How I use AI → footer. Empty sections are hidden.

Content max-width 894px, left aligned. Grid: repeat(4, 216px), gap 10, justify-content start (never centered or stretched). Section gap 52, subsection gap 12. Subsection heading: 22px icon + 15/600 label + count in #A8A59C.

The AI Apps and AI-Powered Software icons in this file are placeholders: use the purple and blue icons you already have.

Responsive and activities

Desktop: 4 columns at 1200+, 3 in the Results preview (fluid, 808px canvas), 2 on mobile (fluid, gap 8).

How I use AI: rows on desktop (title column 280, tags wrap on the right, 1px #EEECE6 between rows). Below 640px the title sits above its tags.

Landing: the hero browser mock uses StackCardRow (6 tools, 2 columns). The social square card underneath keeps the square cards.
