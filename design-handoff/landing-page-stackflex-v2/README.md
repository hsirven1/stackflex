# landing-page-stackflex-v2

The StackFlex landing hero, v2. It shows the AI profile card and a matching LinkedIn banner as one set.

- `components/`: `LandingHero`, `LandingShowcase`, `ProfileFrame`
- `config/landing-samples.ts`: the sample profiles and person
- `styles/landing.css`: the background grid and an optional entrance animation
- `previews/`: reference renders

This package requires `stackflex-results-final` to be integrated first. Start with `CURSOR_HANDOFF.md`.
